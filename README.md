# -8500-bve-
東急8500系東洋製(高音)モーターのモーター音をBVE5.8用に再現したデータです。

【使用方法】
・Soundファイル：車両データのSoundファイルにコピペしてください。パスは適宜変更してください。
・Soundフォルダ：Soundファイル内のパスに従い配置してください。
・Motornoiseフォルダ：車両データVehicleファイル内のパスに従い配置してください。

【注意】
本データの二次配布は不可とします。（参照は可能）


【お借りしたデータ】
本データでは、以下に記すファイルを、それぞれの製作者様よりお借りしています。

BveWorkshop様
・東急8500系モーター音データ
	→音声素材のうち[Motor0～Motor10.wav]を改造の上で使用しました。
	　また、MotorNoiseファイル（Vol.csv、Freq.csv）を改造の上で使用しました。

Train Sound様
・ベースとなるモーター音音源をお借りしました。

以上の製作者の皆様には、この場をお借りして御礼を申し上げます。
